对于 CMMN、BPMN 或 DMN 模型的建模，有一个可以免费注册使用的 Flowable Cloud Design 工具。

## 注册

访问 <https://www.flowable.com/account/open-source> 并注册一个新账户。你将收到一封包含设置密码链接的电子邮件，然后你就可以登录到 Flowable Cloud 登录页面。从那里你可以进入 Flowable Cloud Design 应用程序并开始建模。
你也可以使用以下教程链接获取更多关于如何开始使用 Flowable Cloud Design 的信息 <https://documentation.flowable.com/latest/howto/tutorial/how-put-together>。
